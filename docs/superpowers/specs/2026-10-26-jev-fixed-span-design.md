# 固定 Span 的三提示词实验

用户已确认先实现、验收，再运行此前讨论的固定 Span 实验。

复用已结束的 combined 运行，默认 seed=42，抽取最多覆盖 20 个任务的 100 个调用前 Span。只读关联审计与 SQLite 中 workflow/episode/invocation 三元组，保留完整请求、调用前两项标量、原审计指纹和排除计数。不读取调用后结果作为模型输入，不生成局部正确性或净节省标签。

combined 会去重目标和 assistant 文本，不能直接删除字段作为纯上下文。用每个 workflow 第一调用的空历史审计确认模板消息数、完整目标；随后使用原 JevInputBuilder 从同一个完整请求分别重建三种输入。重建 combined 必须与原审计逐字 JSON 编码一致，否则中止导出，不替换失败样本。无可用审计请求的样本不在本次可重建总体内，覆盖范围必须披露。

数据集保存 samples.jsonl 和 manifest.json（源文件哈希、采样参数、排除计数、样本哈希、每任务抽样数）；拒绝覆盖。实验对每个固定 Span 的三个模式各发一次原生 System One 请求，模式顺序由 seed 打乱。复用 HttpJevClient、响应校验和已验证的 OpenJevPreflight，保留错误、输入用量和耗时；不重试、不压缩、不替换样本。

报告同时给出各模式全部样本统计与三组均成功的配对样本统计、概率差、阈值候选比例、可用性及输入 token。没有执行标签，所有正确率、任务成功率和净节省均不计算。阈值枚举用于探索，不能当作独立测试成绩。

验收：确定性、按任务平衡及阶段覆盖；关联错误和历史去重恢复；输入溢出不发送；一次失败不阻止剩余模式；错误模型响应拒绝；JSON 清单篡改检测；同一候选顺序和提示词；统计分母及配对口径正确。先本地夹具与 HTTP 测试，再服务器真实产物离线重建验收，最后运行真实 Jev。
